# MyGarage1C
# Конфигурация 1С: Мой Гараж

Конфигурация предназначена для ведения учета запчастей и специнструмента в личном гараже, а также позволяет вести учет ремонтов и обслуживания автомобилей. 

Репозиторий содержит выгрузку информационной базы в формате `.cf` файла. По завершению разработки, чистая конфигурация будет выгружена в файлы.

## Статус проекта
Поддерживается разработчиками.

## Содержимое репозитория
- `1cv8.cf` - Файл выгрузки информационной базы (dt). Содержит полную структуру метаданных, данные (если выгружали с данными) и настройки.
- `README.md` - Этот файл.
- `Документация` - Файл с документацией
- `Участники` -  Файл с участниками, их ролями и задачами.

## Требования к окружению
- **Платформа:** 1С:Предприятие 8.3 (версия **8.3.27.1936** или выше).
- **Тип платформы:** Подойдет как коммерческая, так и учебная версия.
- **Лицензия:** Лицензия на использование данной конфигурации не требуется.

## Инструкция по развертыванию

1. **Скачайте репозиторий.**  
   Клонируйте репозиторий или скачайте архив и распакуйте его в локальную папку (например, `C:\1C_Projects\MyGarage`).

2. **Запустите 1С:Предприятие в режиме Конфигуратора.**  
   Откройте список информационных баз (окно запуска 1С) и нажмите кнопку "Добавить".

3. **Создайте пустую базу.**  
   Выберите пункт "Создание новой информационной базы" -> "Создание базы без конфигурации...".

4. **Зайдите в Конфигуратор созданной пустой базы.**  
   Выделите созданную базу в списке и нажмите "Конфигуратор".

5. **Загрузите файл cf.**  
   В меню Конфигуратора выберите **Администрирование** -> **Загрузить информационную базу**.  
   Укажите путь к файлу `1cv8.cf` из папки репозитория и подтвердите загрузку.

6. **Обновите конфигурацию базы данных (если требуется).**  
   После загрузки откройте меню **Конфигурация** -> **Открыть конфигурацию**.  
   Затем нажмите **Конфигурация** -> **Обновить конфигурацию базы данных** (F7). Подтвердите все действия.

7. **Запустите базу в режиме 1С:Предприятие.**  
   Закройте Конфигуратор и откройте базу в режиме "1С:Предприятие" для начала работы.
